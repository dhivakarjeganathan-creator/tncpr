resource.duname - mapped to duname in enrichmentlookup table
resource.primarysite_name - mapped to primarysite_name in enrichmentlookup table

Search the enrichmentlookup table for the searchByProperties parameter and get the list of entityid. This parameter is mandatory
properties - columns that needs to be populated from the enrichmentlookup table comma separated. This can be empty or the properties parameter is optional.
format - will always be json. This parameter is optional
flatten - will always be true. This parameter is optional
entityResourceTypes - should be mapped to type column in enrichmentlookup and should be a search parameter along with searchByProperties. This parameter is optional
